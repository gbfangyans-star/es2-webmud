# 武俠敘述風格指南（招式、閃避、招架、特效敘述用）

整理日期：2026-10-18。依使用者提供的武俠小說文本歸納寫法（學語境、不抄原文）；之後使用者會再提供更多文字，持續補充。
寫任何武功敘述前先看這份。範例句都是自撰，不得把小說原句搬進遊戲。

---

## 一、一句招式的骨架

> **起勢（身形／步法）→ 出手（哪隻手、哪個部位、兵器怎麼動）→ 去向（打向哪裡）**

- 起勢只用一個動作帶過：踏步、矮身、擰腰、側身、縱起、斜跨。
- 出手要說清楚**哪一隻手、哪一隻腳**在做什麼，左右分工是武俠打鬥最有畫面的地方。
- 去向固定落在「$n的$l」（遊戲會換成部位）。
- 一句控制在 25～45 字，用「﹐」切成二到四小段。結尾不加句號（戰鬥訊息會接後文）。

自撰範例：

- $N左足踏前半步﹐右手長劍斜斜一挑﹐劍尖顫處直取$n的$l
- $N身形一矮﹐左掌虛按﹐右拳自肋下穿出﹐搗向$n的$l

## 二、招式名稱放哪裡

招名用「」包起來，常見三種位置，同一套武功要混用，不要每招都同一個句型：

1. **招名在前，當成動作**：「$N一招「〇〇〇〇」﹐……刺向$n的$l」
2. **招名在中，先有起勢**：「$N擰身上步﹐使出「〇〇〇〇」﹐……」
3. **招名接在動作後面點題**：「$N雙掌一合一分﹐正是「〇〇〇〇」﹐……」

**招名的意象要和動作對得上**：叫「鷹」就要有居高撲擊，叫「柳」就要有柔、垂、擺，叫「浪」就要有連綿。
沒有招名的招式，直接寫動作，靠動作本身的意象撐起來。

## 三、動詞要分兵器

| 兵器 | 常用動詞 |
|---|---|
| 劍 | 刺、點、挑、撩、削、抹、圈、絞、斜削、迴鋒、遞出 |
| 刀 | 劈、砍、斫、斬、截、掃、撩、剁、橫削 |
| 鞭 | 抖、甩、捲、纏、砸、掄 |
| 杖、棍 | 點、掃、挑、撐、戳、砸、架 |
| 槍 | 刺、扎、挑、抖、撥 |
| 掌 | 拍、劈、按、推、穿、印、切 |
| 拳 | 搗、錘、衝、砸、撞 |
| 指、爪 | 戳、點、插、扣、抓、拿 |
| 腿 | 踢、踹、掃、勾、蹬 |

同一套武功裡，動詞不要重複超過兩次。

## 四、讓招式活起來的手法

- **虛實與變招**：一手虛晃、一手實擊；招到中途轉向；看似攻上、實則打下。
  例（自撰）：$N左手劍訣虛引﹐右手長劍卻從下路翻起﹐撩向$n的$l
- **速度與力道用四字短語**：快捷無倫、勁力沉雄、去勢奇快、輕靈飄忽、後勁綿長。每句最多一個，不要堆。
- **擬聲**：「刷」「嗤」「呼」「噹」「拍」放在動作前後點一下，例如「呼的一聲」。一套武功裡只放一兩招，太多就吵。
- **方位詞**：斜裏、橫裏、居高臨下、反手、迴身、逕取、直取、下盤、中路。
- **身體部位**（寫攻擊路徑用，不要和 $l 重複）：肩頭、肘底、腕上、腰間、膝彎。

## 五、閃避與招架

- 閃避：側身、矮身、後仰、擰身、斜跨一步、縱起、倒退半步；結果用「撲了個空」「落了個空」「擦身而過」。
- 招架：橫劍封住、圈轉兵刃卸力、手肘搭住來腕、以掌緣切開。招架要寫出**怎麼化解**，不要只寫「擋住了」。
- 閃避句以「$n」開頭，寫完閃的動作就收，不加句號。

## 六、要避免的

- 現代詞彙與語氣（「超快」「瞬移」「暴擊」「技能」）。
- 一句裡兩個以上比喻；形容詞堆疊。
- 每招都「如〇〇般」同一句型。
- 等級數字與指令（見 CLAUDE.md）。
- 直接搬用小說的原句或招名（招名要自創，可以借用同類意象）。

## 七、檢查清單

1. 有沒有起勢、出手、去向三段？
2. 左右手／腳的分工清楚嗎？
3. 動詞符合兵器嗎？同套武功有沒有重複？
4. 招名意象和動作對得上嗎？句型有沒有輪替？
5. 長度 25～45 字、用「﹐」切段、結尾沒有句號？
