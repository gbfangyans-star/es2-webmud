## 陰陽奇門步（magic steps，閃躲 dodge）

1. $n足踏陰位﹐身形一轉已移向陽位﹐$N這一擊落在空處
2. $n依奇門方位斜退半步﹐似虛似實﹐讓$N撲了個空
3. $n身影一分為二﹐一陰一陽各向兩側滑開﹐$N竟不知該向哪一邊出手
4. $n腳下暗合八卦﹐繞著$N輕輕一轉﹐悄然避開了這招

## 火雲奇門步法（eight_steps，閃躲 dodge）

八式對應奇門八門（休、生、傷、杜、景、死、驚、開）：

1. $n踏入「休門」﹐身形如一縷輕煙向後飄開﹐$N這一擊落了個空
2. $n一步轉入「生門」﹐火雲般的衣袂一捲﹐已閃到$N身側
3. $n斜踏「傷門」﹐身子低伏﹐讓$N的攻勢從頭頂掠過
4. $n腳走「杜門」﹐倏地橫移數尺﹐$N連衣角都沒碰著
5. $n步入「景門」﹐身形一晃化作數道殘影﹐$N不知該打哪一個
6. $n反踏「死門」﹐看似自投險地﹐卻在間不容髮之際側身避開
7. $n輕叱一聲踏上「驚門」﹐身形陡然拔起﹐從$N頭頂翻了過去
8. $n由「開門」飄然而出﹐如火雲隨風捲散﹐輕輕巧巧地避過了這招

閃避機率照 ES2 原本公式，步法只提供有效閃避值（和梅影身法、狻猊步法相同）。
