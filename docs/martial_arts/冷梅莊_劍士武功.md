# 冷梅莊（劍士）武功設計草稿

狀態：推演中（尚未製作）。來源：使用者設定（2026-10-06），招式敘述取自 `對戰紀錄_梅影風vs柳東蘆.md`。
標記：NEW（新版武功寫法）。

## 武功組成

| 武功 | 裝備位置 | 內容 |
|---|---|---|
| 冷梅劍法 | 右手劍（sword），同時可作為招架（parry） | 六招攻擊；招架時用四招拆招卸力敘述；招架後有機會反擊 |
| 傲梅暗劍訣 | 左手劍法（副手） | 六招攻擊；出招時有機會發動梅二方劍、梅四方劍，累積點數發出愛霜恨雪 |
| 寒梅心法 | 內功（force） | `exert mirror` 進入明鏡止水；明鏡止水狀態下可觸發寒霜三千里 |

## 冷梅劍法（右手）

### 攻擊招式

| 招式 | 敘述 |
|---|---|
| 力能貫日 | $N使出「力能貫日」，手中$w劃出一個耀眼的光輪，$N身形回斂凝力於劍，透過光輪直刺$n的$l |
| 寒風飄雪 | $N使出「寒風飄雪」，手中$w隨著身形由左往右順勢一帶，幻出一道劍浪劃向$n的$l |
| 花枝亂顫 | $N使出一招「花枝亂顫」，$w搖晃著化為數道劍影從各個不定的方位分襲向$n的$l |
| 白虹經天 | $N順勢轉身一招「白虹經天」，手中$w劍身化成一道白光挾著銳嘯以劇力萬鈞之勢直劈向$n的$l |
| 漫天花影 | $N一式「漫天花影」使將出來，手中的$w倏地朝空一立，劍尖由上而下顫出了無數的劍花罩向了$n的$l |
| 柳暗花明 | $N身形一矮，往前大跨一步，手中$w一招「柳暗花明」倏地劍勢一頓，由虛轉實由下而上回撩$n的$l |

### 招架（拆招卸力）

| 招式 | 敘述（$n＝招架者，$N＝攻擊者） |
|---|---|
| 寒梅蕭蕭 | $n應以一招「寒梅蕭蕭」，擋住了$N的攻勢 |
| 橫梅四處 | $n手中$w急轉，一招「橫梅四處」將$N的來勢一一封住 |
| 寒霜隔梅 | $n手中$w一揮，一式「寒霜隔梅」將$N的攻勢化解掉 |
| 冷梅紛紛 | $n手裡遞出一招「冷梅紛紛」將$N的所有攻勢化解掉 |

### 招架反擊

招架成功後有機會觸發：

> $N架開$n的攻擊，順勢舞出二道寒冷的劍氣直指$n週身要害！

## 傲梅暗劍訣（左手劍法）

### 攻擊招式

| 招式 | 敘述 |
|---|---|
| 梅影幢幢 | $N右手劍招倏地一收，左手一劍「梅影幢幢」閃電般劃向$n$l |
| 傲梅藏鋒 | $N趁著冷梅劍法攻勢未盡，左手冷不防一招「傲梅藏鋒」刺向$n$l |
| 梅厲風行 | $N左劍暴然向前疾探，一招「梅厲風行」又快又準地刺向$n$l |
| 暗劍難防 | $N右手劍招一停，左手劍招「暗劍難防」跟著遞出，斜刺$n$l |
| 梅落何方 | $N右手一劍刺出，身子順勢一個迴翻，左手一招「梅落何方」，$w對準$n$l一陣疾刺 |
| 雪蛇弄梅 | $N一聲清嘯，左手$w突然彈跳而出，「雪蛇弄梅」一招瞬間貼身遊至$n$l |

### 梅二方劍／梅四方劍 → 愛霜恨雪

- 左手出招時，有機會發動梅二方劍或梅四方劍。
- 發動梅二方劍得 2 點，發動梅四方劍得 4 點。
- 累積到 7 點就發出愛霜恨雪，同時清空點數。

> $N施展傲梅暗劍訣中的殺招【梅二方劍】！
> $N全力施展快劍，幻化出了二道劍氣將$n團團圍住！

> $N施展傲梅暗劍訣中的殺招【梅四方劍】！
> $N全力施展快劍，幻化出了四道劍氣將$n團團圍住！

> $N意猶未盡，手上$w突然斜裡翻出劍尖急顫！
> $N施展傲梅暗劍訣中的殺招「愛霜恨雪」！一股無形的冷冽氣勁朝著$n直射而出！

### 冰凍

> $N招式之間寒冷的傲梅劍氣將$n凍得面起白霜，渾身發抖 ...

凍結對手，使其停頓（delay）1 回合，並造成少量傷害。

## 寒梅心法（內功）

### 明鏡止水（exert mirror）

> $N心靜若水眼明如鏡，竟漸入【 明 鏡 止 水 】之境界！

提升攻勢等級、攻擊能力值；在此狀態下才能觸發寒霜三千里。

### 寒霜三千里

只在明鏡止水狀態下發動，發動時讓對手停頓 2 tick。

> $N催運寒梅心法使出【寒霜三千里】劍氣，$w劍刃嗤嗤做響，$n全身瞬間蒙上一層白霜！

## 已定案數值

| 項目 | 規則 |
|---|---|
| 招架反擊 | 冷梅劍法招架成功後，機率約 50%（估算） |
| 梅二方劍 | 傲梅暗劍訣出招時，機率約 9%（估算）；需傲梅暗劍訣 80 級；傷害＝2 下普通攻擊；+2 點；耗精為普攻 120% |
| 梅四方劍 | 傲梅暗劍訣出招時，機率約 18%（估算）；需傲梅暗劍訣 100 級；傷害＝4 下普通攻擊；+4 點；耗精為普攻 140% |
| 愛霜恨雪 | 點數累積到 7 點時發動並清空；傷害＝普通傷害 300%；耗精為普攻 150% |
| 冰凍 | 傲梅暗劍訣的特效；機率約 13%（每次左手出招，估算）；對手停頓 1 回合並受少量傷害；耗精為普攻 110% |
| 明鏡止水 | `exert mirror`；攻勢等級 +寒梅心法÷4，攻擊能力值 +寒梅心法÷2；持續時間 =（定力×2 + 機敏）+ 寒梅心法÷5 |
| 寒霜三千里 | 明鏡止水狀態下，每回合機率約 30%（估算）；需冷梅劍法 100 級；對手停頓 2 回合；無傷害 |

回合＝tick（遊戲每回合約 2 秒）。

機率估算來源（`對戰紀錄_梅影風vs柳東蘆.md`）：招架約 56～61 次、反擊 28 次；左手出招 113 次、梅二方劍 10 次、
梅四方劍 20 次、冰凍 15 次；右手出招（約等於回合數）32 次、寒霜三千里 10 次。依點數推算愛霜恨雪約 14 次，
紀錄裡出現 12 次，與「7 點發動」吻合。

## 寒梅心法（定案）

| 指令 | 效果 |
|---|---|
| `exert refresh` | 消耗 寒梅心法÷3 的氣（kee），回復 寒梅心法 的精（gin） |
| `exert recover` | 消耗 寒梅心法÷10 的精，回復 10＋寒梅心法÷8 的氣上限（受傷減少的部分），回復 10＋寒梅心法÷5 的氣 |
| `exert hainmay force` | 修習寒梅心法；每次修練得到 基本公式＋random(定力) 的熟練度 |
| `exert mirror` | 需寒梅心法 100 級；每次扣 100 點目前的氣；沒有冷卻 |

寒梅心法練到 100 級：膂力 +1、膽識 +1、精上限 +100、氣上限 +100。

其他定案：
- 「練成」＝先累積修練，達標時直接跳到 20 級並顯示訊息。
- 明鏡止水持續時間單位為回合（tick），定力、機敏含裝備加成。
- 冰凍的少量傷害＝普通傷害 30%。
- 三套武功的上限與升級獎勵比照三門刀法（上限 200；武術造詣 sk×10；30 級起武學之道 (sk−11)×10）。
- 暫不製作師父 NPC。
