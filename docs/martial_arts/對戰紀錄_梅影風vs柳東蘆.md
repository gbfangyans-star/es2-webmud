## 戰鬥訊息格式（與現行遊戲不同之處）

**結果句**（接在防禦敘述後面）：
- 不料$N力道實在兇猛，結果只是輕輕地刺破$n的皮肉。
- 怎料$N這招來得太快，結果只是輕輕地劃破$n的皮肉。
- 不料$N這一擊來得太快，結果在$n$l刺出一個創口。
- 但只卸去了$N部分勁道，結果只是輕輕地劃破$n的皮肉。

**體力狀態句**（跟現行遊戲的用字不同，例如）：
- ( $N看起來對這種程度的攻擊一點也不在乎。 )
- ( $N似乎有些疲憊，也許是誘敵之計，但你無法確定。 )
- ( $N看起來可能有些累了，進退趨避之間開始有些滯塞。 )
- ( $N漸露疲態，惡鬥之下顯得有些吃力。 )
- ( $N不住地喘氣，看來體力的消耗相當嚴重。 )
- ( $N在激鬥之中氣喘噓噓，看起來狀況不太妙。 )
- ( $N的動作開始有些拖泥帶水，似乎有些力不從心了。 )
- ( $N明顯露出疲態，顯然已在苦苦支撐。 )（紅字）

**死亡**：柳東蘆趴在地上，無力地掙扎了一會兒，隨即死去。
