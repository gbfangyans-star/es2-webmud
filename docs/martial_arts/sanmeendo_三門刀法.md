# 三門刀法（sanmeendo）— 武功敘述草稿

狀態：草稿，待確認。強度數字見 `武功強度設定表.xlsx`。
標記：NEW（新版武功寫法）。

## 構想（提供者原文整理）

- 虎刀門入門刀法，enable 在 blade
- 主要用途：提升武術造詣；練到 30 級後開始獲得武學之道
- 易練好上手，威力不強，適合入門
- 全套 5 招
- 每出三招且命中對手後，有機會一鼓作氣將三招快速再使一次，故稱三門刀法

## 武功簡介（查看武功時顯示）

> 虎刀門入門刀法。刀路分中、側、反三門，招式樸實、易學易練，
> 威力雖然平平，卻是打熬根基的好功夫。三刀連中之際，往往能一鼓作氣
> 再走一遍三門，故名「三門刀法」。

## 招式（每招一行）

| 順序 | 招式名 | 敘述 |
|---|---|---|
| 1 | 開門見山 | `$N踏前一步﹐使出「開門見山」﹐$w當頭劈向$n的$l` |
| 2 | 迴門藏鋒 | `$N刀貼腰側一轉﹐「迴門藏鋒」﹐$w自旁翻出削向$n的$l` |
| 3 | 側門截勢 | `$N腳下一錯﹐「側門截勢」﹐$w斜斜截向$n的$l` |
| 4 | 中門直進 | `$N沉肩直進﹐「中門直進」﹐$w迎面斬向$n的$l` |
| 5 | 反門回刃 | `$N退步回身﹐「反門回刃」﹐$w反手捲向$n的$l` |

## 特別招式：三門齊開（整套特效「三招重演」）

觸發時（黃色）：

```
$N三刀接連得手﹐精神一振﹐低喝一聲﹕「三門齊開﹗」
$N刀勢不停﹐將方才三招一氣呵成﹐再使一遍﹗
```

接著依序重演剛才那三招（使用原本的一行敘述）。

結束時（青色）：

```
$N三門走罷﹐收刀回勢﹐氣息微微一喘。
```
