# 玩家版天朝圖鑑（討論稿）

狀態：**討論稿，尚未製作**。使用者確認後才開始寫程式。

## 一、目標

做一份給玩家看的天朝圖鑑，只列出**遊戲裡已經實裝、玩家走得到**的內容：
地圖、NPC、門派、技能、裝備與物品。

- 不公開公式：升級門檻、傷害計算、學成點數等都不寫。
- 技能會說明「練了會增加哪些屬性」，例如「修練有成時，膂力與根骨會隨之增長」，但不寫數字。
- 現有的巫師版圖鑑（`docs/catalog/es2_catalog.html`，含公式、檔案路徑、未實裝內容）保留不動，兩份分開。

## 二、「以地圖為基礎」怎麼判斷

從玩家出生的雪亭鎮客棧大堂出發，沿著房間出口一路往外走，**走得到的房間才算實裝**：

| 內容 | 算「實裝」的條件 |
|---|---|
| 房間、區域 | 從客棧大堂沿出口（含 climb、search 等特殊進出方式）走得到 |
| NPC | 被放在走得到的房間裡 |
| 裝備、物品 | 走得到的房間地上擺的、走得到的 NPC 身上穿戴或攜帶的、走得到的商店賣的 |
| 技能 | 走得到的師父教的、走得到的書能讀的，或上面列出的裝備會用到的武功 |
| 門派 | 掌門或師父是走得到的 NPC |

自動排除的內容：
- 還沒接上地圖的區域（做到一半的地方）
- 巫師工作室、家園等系統房間
- 沒被放在任何房間的 NPC、沒有任何取得方式的物品

做不到自動判斷的：NPC 死後才掉落、任務獎勵等寫在劇情程式裡的物品。這類東西**待確認**（見第六節）。

## 三、各分頁內容

### 地圖
- 依區域顯示房間格子圖（沿用巫師版圖鑑的排版），點房間看描述、出口、這裡有哪些 NPC 與物品。

### NPC
- 名稱、外觀描述、出沒地點（點了跳到地圖）。
- 販賣的商品、可以拜師或學的武功（如果有）。
- 戰力數值（等級、技能等級、屬性）：**待確認**。

### 門派
- 門派名稱、所在地、掌門與師父、門下武功。
- 入門條件：**待確認**。

### 技能
- 名稱、分類（武學、法術、知識……）、說明文字。
- 修練會增長的屬性（只寫屬性名稱，不寫數字）。
- 去哪裡學：師父、門派或書籍。
- 不寫：升級門檻、學成點數、等級上限的計算方式。

### 裝備與物品
- 名稱、外觀描述、種類（刀、劍、衣服、戒指……）、取得地點或來源 NPC、價格。
- 能力數值（傷害力、防禦力、屬性加成）：**待確認**。

### 文字規則
比照遊戲內的敘述規則（`CLAUDE.md`）：
- 不寫等級數字，例如不寫「需要三十級」，改寫成「火候未到不能學」這類說法。
- 不寫指令名稱。
- 不顯示程式路徑、英文代碼。

## 四、放在哪裡、怎麼更新

- **放在遊戲網站上**（建議）：做成 `https://161-118-234-100.sslip.io/codex.html`，遊戲畫面左側選單加一個「圖鑑」連結，玩家不用登入也能看。
- **自動更新**（建議）：主機每次執行 `update.sh` 時自動重新產生，內容永遠跟遊戲一致，不用另外手動同步。
- 產生程式沿用巫師版的 `tools/build_codex.py`，加一個「玩家版」模式，分析程式碼只寫一份。

## 五、會改到的檔案

| 檔案 | 內容 |
|---|---|
| `tools/build_codex.py` | 加入「從出生點走得到」的判斷與玩家版輸出 |
| `tools/codex_player_template.html`（新） | 玩家版網頁樣板 |
| `web/codex.html`（產生） | 玩家版圖鑑本身 |
| `web/index.html` | 左側選單加「圖鑑」連結 |
| `deploy/oracle/update.sh` | 更新時自動重產圖鑑 |

不會動到遊戲本身的程式（戰鬥、技能、NPC、房間）。

## 六、待確認事項

1. **放在哪裡**：遊戲網站新頁面（建議），還是另外的分享連結？
2. **隱藏路徑**：要 search、climb 等特殊動作才能發現的房間與通道，要顯示嗎？
   （建議：房間顯示，但不說明怎麼進去，保留探索樂趣。）
3. **裝備數值**：傷害力、防禦力、屬性加成要顯示嗎？
4. **NPC 戰力**：等級、技能、屬性要顯示嗎？（建議：不顯示，只寫出沒地點與描述。）
5. **門派入門條件**：要寫出來嗎？（例如種族、職業限制。）
6. **掉落物與任務獎勵**：程式無法自動判斷，要不要先不列？還是由使用者另外指定要公開哪些？
7. **更新方式**：每次更新主機自動重產（建議），還是手動確認後才發布？
