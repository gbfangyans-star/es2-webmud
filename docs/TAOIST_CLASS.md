# 道士職業

職業代碼為 `taoist`。以下數值是升到「目標等級」所需的**累積**分數，不會在升級時扣除。

| 分數 | 升級門檻 |
| --- | --- |
| 江湖歷練 (`survive`) | `(目標等級 - 1)^2 × 100` |
| 法術修為 (`magic`) | `(目標等級 - 1)^2 × 150` |
| 咒術道行 (`spell mastery`) | 目標等級 11 起：`(目標等級 - 10)^2 × 100`；此前為 0 |
| 實戰經驗 (`combat`) | 目標等級 12 起：`(目標等級 - 11)^2 × 100`；此前為 0 |

例如升 11 級需江湖歷練 10,000、法術修為 15,000、咒術道行 100；升 12 級需江湖歷練 12,100、法術修為 18,150、咒術道行 400、實戰經驗 100。

每次升級增加最大精 `⌊原始機敏 / 4⌋ + random(3) - 1`、最大氣 `⌊原始根骨 / 4⌋ + random(3) - 1`、最大神 `⌊原始靈性 / 3⌋ + random(3) - 1`。三項分別擲出 −1、0 或 +1，並先以整數除法捨去屬性除法的餘數。種族升級若先提升原始屬性，當次職業增量採用提升後的值。

每次有效施法取得法術修為 `1 + random(咒文重數 + 1)`，其中 `random(N)` 產生 0 至 N−1；第一至第四重分別取得 1–2、1–3、1–4、1–5 點。咒術道行不再由命中累積，而是火、冰、風、雷四系各自以 `max(技能原始等級 - 10, 0)^2 × 10` 計算後加總；技能設定、提升或刪除時即更新。命中後仍取得實戰經驗 `min(1 + 效果量 / 40, 20)`；無相冰命中以咒文強度基數作效果量。實戰經驗速率仍是暫定平衡值。

仍需設計道士入職、四系技能的學習途徑，以及非戰鬥施法是否應給分。現有種族職業等級上限照常生效。
