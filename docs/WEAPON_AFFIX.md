# 武器附加屬性（隨機前綴／後綴）

依 es2_pal「武器附加屬性表」製作，套用在 `obj/area/obj/` 的 12 種一般武器：長劍、短劍、單刀、鬼頭刀、大劍（bastardsword、greatsword）、闊劍、彎刀、大刀、板斧、長槍、鐵鞭，以及竹釣竿（`custom/weapon/whip/bamboo_fishing_rod.c`）。

## 規則

- 每把武器**產生時**擲一次（NPC 身上、商店販賣、地上產生都一樣）：普通 60%、只有前綴 30%、前綴＋後綴 10%。
  **必須有前綴才會有後綴。**
- 名稱為「前綴＋後綴＋原名」，例如「黑鋼長劍」「精鋼火炎長劍」。前綴、後綴各用表上的顏色，原名不上色。英文 id 不變。
- 武器原本的特性會保留，詞綴加在上面（例如竹釣竿的捕魚技巧 +3）。
- 加成在這把武器的每一種用法（例如劍術、左手劍術）裝備時生效，卸下即消失。
- 每個修飾讓價值變成 1.5 倍（前綴＋後綴為 2.25 倍）。
- 結果記在武器的 `affix`（`([ "prefix": …, "suffix": … ])`）。家園儲物箱會照存，取出時原樣還原（普通武器也不會重擲）。
- 程式：`adm/daemons/enhanced.c` 的 `roll_affix()`、`apply_affix()`。`AFFIX_COLOR` 設為 0 可改成全部不上色。原本只在 NPC 身上強化的 `enhance_weapon()` 已不再使用。

## 竹釣竿

- 比生鐵釣竿弱的一般釣竿：軟鞭鞭法，傷害 6–24（生鐵釣竿 10–43），重 3500，價值 20 兩，特性只有捕魚技巧 +3。
- 五堂鎮鯉君渡口的兩名釣客各拿一支，產生時同樣擲詞綴。
