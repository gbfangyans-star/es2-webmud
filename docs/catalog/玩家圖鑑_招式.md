# 玩家圖鑑：武功絕招與內功運用

玩家版天朝圖鑑（`web/codex.html`）的「技能」分頁讀這份表格，在武功、內功底下列出練到某個程度才會的
絕招、殺招與運功方式（使用者指示，2026-10-24）。規劃見 `docs/PLAYER_CODEX_PLAN.md`。

- 一般招式（技能檔 `moves` 裡的招式名稱與 `lvl`）由圖鑑程式自動讀取，不用寫在這裡。
- 「等級」寫幾級起才有；寫「學會」表示一學會就能用。
- 「指令」寫運功指令（exert）；被動發動的絕招不用指令，留空。
- **不寫經驗值（累積點數）的計算公式**。
- 內容依各技能檔的程式整理（2026-10-24）；技能改版時請一起更新這份表格。
