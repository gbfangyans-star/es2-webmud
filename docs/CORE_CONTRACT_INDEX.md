# Core Contract Index

v1.0 adds source-shape indexes for four high-risk areas without moving authority out of LPC:

- Skill contracts: `valid_enable`, `valid_learn`, improvement/advance hooks, attack/dodge/parry dispatch, exert/perform/practice hooks.
- Equipment lifecycle: wear/remove/wield/unwield and setup/query hooks.
- Damage contracts: strength/ability/defend/absorb/inflict/receive/attack/fight selection interfaces.
- Interactive object hooks: add_action, accept_object/accept_fight, call_out and doors.

These indexes are navigation aids. They do not evaluate LPC, resolve dynamic inheritance, or recreate gameplay in JavaScript.
