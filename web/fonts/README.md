# ES2 Mono

網頁終端機的英文、數字與符號字型。

- 來源：Sarasa Mono 0.36.0（更紗黑體，https://github.com/be5invis/Sarasa-Gothic），SIL Open Font License 1.1，授權全文見 `OFL.txt`。
- 修改：只保留英文、數字、拉丁字母、標點、框線、方塊與幾何符號（U+0020–007E、U+00A0–024F、U+2000–206F、U+2100–21FF、U+2500–26FF），並依 OFL 規定改名為「ES2 Mono」。
- 中文由 Google Fonts 的 Noto Sans TC 提供（與更紗黑體的中文同源，即思源黑體，繁體字形）。
- 英文半形寬 0.5em、中文全形寬 1em，剛好一個中文字等於兩個英文字，`who`、`score` 等排版才能對齊。
