ES2 WebMUD 單機測試版
======================

朋友第一次拿到專案後：
1. 雙擊「啟動單機測試版.bat」
2. 瀏覽器會自動開啟，不需要輸入 IP
3. 測試管理者帳號：testadmin
4. 測試管理者密碼：test

單機測試版：
- 只使用 127.0.0.1，本機自己連自己
- 不需要路由器開 Port
- 不需要知道外網 IP
- 不會使用或回寫正式多人版的玩家存檔
- 每次啟動會同步目前專案程式碼，但保留自己的單機測試角色
- 要清空測試角色時，雙擊「重置單機測試資料.bat」

注意：
- Windows 電腦需要安裝 Node.js LTS。第一次啟動若缺 WebMUD 套件，腳本會自動 npm ci。
- GitHub 上不應上傳正式玩家 data/user、data/login、log 或 .local-test。
- 正式多人版原帳號與管理者權限不會被這個單機模式修改。
